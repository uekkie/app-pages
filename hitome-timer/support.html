サポート

ご意見や不具合報告は、GitHub Issuesからお知らせください。投稿には GitHub アカウントが必要です。個人情報は公開の Issue に書き込まないでください。

よくあるご質問

画面を閉じると通知されません。 アプリ内の「設定」で通知状態を確認し、許可がない場合は iPhone の「設定」から通知を許可してください。集中モードや消音設定によって通知音は変わります。

残り時間が変わりました。 端末の現在時刻を基準にするため、システム時刻を手動で変更すると残り時間も変わります。

設定が保存されません。 端末の空き容量を確認し、アプリを再起動してください。
